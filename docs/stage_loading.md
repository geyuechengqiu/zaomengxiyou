# 关卡加载界面

点击花果山、水帘洞时显示原版上古天帝篇加载背景、进度槽、云朵游标。
标题使用原版“造梦西游Online”主体，通过 AtlasTexture 裁掉副标题。
界面节点及控制器预置于 `game/loading/stage_loading_screen.tscn`，逻辑为 `StageLoadingScreen.cs`。选关时通过 `ZaomengOneCampaign.GetLoadingScreen()` 首次实例化，并挂在根视口中覆盖场景切换，之后复用；直接编辑/测试关卡无需创建控制器或加载这组UI资源。

`data/campaigns/zaomeng1/world_map.json` 每个已接入关卡配置 `scene`、`loading_manifest`、`loading_audio`。
新增关卡时填写它们；加载器从清单读取角色、技能、状态、装备、区域及怪物定义，并遍历音频配置预载音频文件。
动态出生的怪物与Boss场景随定义提前加载。加载器在独立的预置 `WarmupViewport` 中实例化纯动画场景，采样角色、怪物各个动作及技能特效，提前上传纹理并准备渲染；完成后释放预热节点，不提前生成战斗敌人或推进战斗。

进度前85%对应各资源组的实际加载比例；最后15%对应场景入树、Ready初始化、角色存档恢复、装备属性和HUD绑定、战斗配置预热及渲染准备。
逻辑进度只在实际加载/初始化完成后推进。显示进度使用0.8秒Quad/Out Tween，从当前显示值缓动至逻辑进度，云朵和百分比同步跟随；相同进度的重复通知不重启缓动。可在加载场景根节点的 `ProgressTweenSeconds` 调整时长（0.3–2秒）。最终缓动结束并绘制100%后才隐藏遮罩、恢复战斗与输入。带C#/Spine脚本的资源分批在主线程加载，批次之间让出帧绘制界面；普通音频使用后台线程并读取实际加载比例。主线程入树期间进度会暂时停留；后台线程不执行场景节点初始化。
关卡入树时预分配8个怪物反馈实例及128个跳字实例，随后完成角色存档、装备、技能按键、HUD和摄像机绑定，并等待延迟初始化及画面绘制完成。战斗中实际出怪、命中和掉落仍按战斗时间生成，超出池容量的有效反馈不会丢弃。
加载界面先绘制一帧再执行初始化，界面遮挡下层输入；初始化完成前暂停战斗时钟和玩家操作。加载失败显示原因并可返回重试，选关进度与玩家存档不清空。

大地图使用造梦西游1原选关音乐 `assets/audio/zaomeng1/world_map.mp3`（Music.swf/begin），与原版 `GMain.showStageMap → SoundManager.play("begin")` 一致；沿用音乐音量和静音偏好。花果山关卡仍使用bg1。
所有自动测试，包括GPU截图，必须传入 `--audio-driver Dummy`；不会修改真实玩家音频偏好，F5/F6与正式游戏不强制静音。

重复进关按资源路径复用强引用缓存，不重新提交音频线程请求；纯动画场景完成过预热后不再次实例化。`ResourceLoads`、`VisualPreparations` 是累计实际工作计数，`WarmedVisualCount` 表示本关所需画面已就绪的数量，包含缓存命中。缓存只在本次游戏进程中有效，修改素材后重新运行；退出时释放缓存引用。

造1重开通过同一加载流程，依然创建独立战斗实例并恢复玩家数据。加载控制器中途离场会恢复暂停状态并只回调一次失败，异步等待恢复后不再访问已释放的场景节点。进度云朵按主体锚点对齐进度条末端及中心线；发行水印使用背景shader局部修补，原底部文字与其他区域保留。

验证：`campaign_transitions` 覆盖花果山→通关→地图→水帘洞→重开→地图，以及失败恢复、进度单调、初始化暂停、标题裁切、地图音乐和存档恢复。GPU截图在该测试后加 `-- --loading-capture`。
使用 `tools/ExportOriginalBattleUI.java` 导出 preload_20230619_1.swf 的 #14、#16、#19、#21、#30 至 `.cleanup-backup/loading-parts`，再运行 `tools/author_loading_ui.py` 可重新生成预置界面。
