# 悟空原版普攻受击参数

第一关索引引用这里的五段普攻、跑攻与跳攻。阶段9的 `hit_reaction` 资源保留作为受击、倒地与保护功能验收夹具；不再用于第一关。这里从已编辑的基础技能复制命中帧、倍率、判定框和时间线，仅补充原版受击参数。

原配置和换算记录见 [source.json](source.json)。`SkillParam.buildFromObject()` 中空 `targetMove` 继承技能配置，而 `stiff` 可以被当前攻击段覆盖。`CharEntity.TargetMove()` 每次命中覆盖旧速度、撤销旧计时器；时长优先 `targetMoveTime`，否则使用 `stiff`，小于等于0时取1秒。不能把速度理解为距离，也不能把连续命中产生的速度相加。

当前战斗坐标是原版的2倍。水平速度为原版X×2；竖向初速度为原版Y×6，受击重力为1980，与基础技能的Nape换算一致。下表为不受墙体、霸体、抗性或后续命中影响时的水平位移；实际受击由插件运动控制器扫掠碰撞，不穿墙。

表中正负值按攻击方向镜像，第三段是拉回。普攻4第二击覆盖第一击剩余冲量；因此两击连打不能简单相加表中的完整位移。原版Y分别为40、40、40、40、40、80、60、40，保留竖向受击，移除第一关原先使用的测试用强制倒地及额外停顿。

编辑入口是各技能的 `Timeline → Events → Payload`，跑攻与跳攻为 `Timeline → Attack Segments → Hit`。`knockback_speed` 使用世界像素/秒，`knockback_duration` 使用战斗秒；如只调整怪物抗性，可在该类角色的 `Reaction Profile → Knockback Resistance` 设置0～1，默认0保持原版参数，不影响竖向击飞。
