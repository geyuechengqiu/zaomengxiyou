# 造梦西游1大地图与跨关进度

项目 F5 入口为 `game/world_map/zaomeng1_world_map.tscn`。地理背景及十个原选关点来自造1 `OtherMat_v5.swf/export.SelectPLace`，顺序为1-1至3-3、4-1。当前只有花果山、水帘洞完成关卡实现；其他点保留原位置，但场景路径为空，不能进入。

地图保留造5原返回图标、按钮三态、字体和面板主题；点击已解锁且已制作的地图点直接进入关卡，不再弹出二级选关窗口。仅最新可实际挑战的关卡使用造1原图标第三帧的黄色发光，悬停切至原第二帧，移开恢复发光；其余关卡不发光。未制作点即使已解锁也不会抢占可挑战高亮。返回图标在有最近挑战关卡时显示，点击重新进入该关卡；底部“碧玉径”保留原主关卡入口。地图音乐接入 Core 的音乐音量/静音设置。

`world_map.json` 是关卡顺序、语义ID、名称、入口路径、简介、来源符号和位置的索引。新增关卡时填写 `scene`，添加相应 C# `ZaomengOneLevelScene` 子类的 `CampaignId`，并在地图场景中预置对应图标及 `metadata/latest_texture` 原第三帧纹理。关卡场景需要预置 `HUD/CampaignResult`。区域内出生、锁定和最终胜利仍交给关卡流执行，选关系统不自行按活怪数推断完成。

`ZaomengOneCampaign` 是预置自动加载，记录胜利前检查关卡流已经确认最终出口、关卡ID匹配及战斗ID未结算。清屏或 Boss 死亡不会提前解锁，重复回调不会重复结算。通关后显示结果面板，可回大地图或重新挑战；中途返回/失败不解锁。切换场景释放旧会话，保留角色数据。

存档为 `user://zaomeng1-campaign.cfg`，版本1，包含已完成关卡集合和角色状态。读取后根据连续通关链恢复解锁顺序。返回地图、重开、通关或关闭窗口时保存：

- 等级、当前经验、灵魂、昵称及角色编号。
- 背包容量、物品数量/锁定、物品唯一ID、强化、随机/附加属性。
- 穿戴槽及其独立装备实例，外观开关。

进入另一关时通过物品定义重新创建实例，恢复实例状态及所有权，并走统一装备通知重算实际属性/外观；生命、魔法补满。角色场景的基础属性仍可编辑，临时 Buff、冷却、无双及旧关敌人不会被带到下一关。不要编辑测试目录中的隔离存档来调整真实进度。

`tools/author_zaomeng_one_map.py` 从离线 SWF 导出缓存重建资源及地图按钮，保留花果山手动场景位置；普通运行不依赖导出缓存。地图图像位于 `assets/ui/zaomeng1/world_map/`，共用主题为 `data/ui/campaign_theme.tres`，结果面板为 `data/ui/campaign_result.tscn`。

离开大地图时解除音乐循环订阅、停止播放器并释放流；配套引擎的混音线程需要完成排队的回收，因此仅在场景退出时等待下一次混音，等待上限80毫秒，不在游玩每帧执行。

`zaomeng_one_campaign` 检查原地图/造5 UI、真正最终出口解锁一次、磁盘读写、装备唯一ID与实际属性跨关恢复；`campaign_transitions` 通过真实按钮执行大地图→花果山→胜利面板→地图→水帘洞→重开→地图。测试只清理自己明确隔离的用户目录，适用于 Debug 和 NativeAOT。
